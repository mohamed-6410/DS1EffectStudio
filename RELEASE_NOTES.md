# v0.1.0

Windows desktop FFX editor for Dark Souls Prepare to Die Edition. Includes multiple selection, native model/texture replacement, grouped timeline names, rotation in degrees, sound-ID insertion and local FSB preview. Editing preserves camera and zoom and keeps the old scene visible until replacement resources are ready.

Game files are read from your own installation and are not distributed. Preview rendering approximates the game runtime; native exports are structurally validated.
