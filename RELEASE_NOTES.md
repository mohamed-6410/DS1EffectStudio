# v0.1.0

Windows desktop FFX editor for Dark Souls Prepare to Die Edition. Includes multiple selection, native model/texture replacement, grouped timeline names, degree rotation, sound-ID insertion and local FSB preview. Editing preserves camera/zoom and swaps prepared scenes without a blank flash.

Game files are read from your own installation and are not distributed. Preview rendering approximates the game runtime; native exports are structurally validated.
